## 4. 视觉检查与参考差异

检查过旧版首页、新版首页、鸟瞰、驻足、徒步近景的真实浏览器截图（工具直接返回图片）。本轮没有把截图写入此前受限的截图目录，也没有换渠道绕过限制。**严格同视点/同尺寸的前后对比截图文件尚未交付**；原型无真实地理对应，不宣称旧/新画面是相同地理机位。

参考国家林草局页面中的石河和峰顶照片，只用于地貌、岩块形态和草甸分布方向的对照，不把照片混入发布包。已看到的差异：
- 现在的山体轮廓由 DEM 决定，而不是旧版随机环带山；远近关系有数据依据。
- 源数据及降采样会平滑小地形；地表材质、石块密度和草簇仍明显简化，**不是照片级石海**。
- 没有还原庙宇、题字、冰雪、湖泊、真实植物种类或原照片机位；当前视点/季节光照为艺术编排。
- 首轮截图发现岩块在坡面悬浮：加入坡面四元数、减少抬升，渲染和物理同步调整；补测试并再次查看徒步截图，已不再出现该轮中的明显离地岩块。

因此地形数据一致性通过开发检查，整体“像不像鳌太”的视觉验收仍请用户确认。若需要摄影级质量，应在此阶段追加合法 PBR/扫描资产或精细美术，不直接跳到声音/天气阶段掩盖问题。
