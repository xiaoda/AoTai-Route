**状态：功能实现和技术检查完成，等待用户视觉体验验收。** 用户已明确不要声音，并确认晴朗/多云/薄雾范围。阶段 2 已通过的 2.23 公里及三节点不改造，不进入阶段 4/5。

## 1. 交付范围

- 六分钟前台时间循环：晴朗停留 0—30 秒；30—100 秒转多云；100—140 秒多云；140—220 秒转薄雾；220—260 秒薄雾；260—360 秒放晴。
- 统一状态驱动天空色、云量、云漂移、直接光、环境光、地表云影及指数距离雾。
- 右上天气手记可选择自动 / 固定晴朗 / 固定多云 / 固定薄雾。手动约 12 秒渐变；中途反选从当前权重开始。固定类型仍移动云，暂停自动相位；回自动平滑接回保存的相位。
- 暂停、设置弹窗、blur/隐藏页面时冻结云及天气。恢复首帧丢弃 delta；长卡顿帧最多推进 0.1 秒，后台时间不追赶。
- 保留旧设置键 aotai.settings.v1，增加白名单 weather；只保存选择，不保存天气时钟。旧数据默认 auto，刷新固定类型从对应预设开始。
- 所有自然材质共享一张 256×256 程序云图、同一风偏移和云高度/光向。地形与岩块原有材质 hook、植被渐隐被组合保留，云影仅作用于直接光。
- 云是平面投影近似，雾是距离雾；不是体积云、谷地体积雾、实时气象或实地安全信息。**没有任何声音、雨雪、雷电、湖面、日夜或旅程存档。** 无新增运行依赖，无运行时外部网络资源。

- 正式 UI 选择多云、薄雾和晴朗，实际截图可见：多云的山坡明暗、薄雾的远山退隐与近处石块保留、晴朗时远山恢复。

- 暂停后连续 1.8 秒的时刻、云偏移、雾和光照完全不变；暂停中选择晴朗，仍保持薄雾画面，恢复后才过渡。
- 派发普通 blur / focus 事件，体验进入暂停，天气和云偏移冻结。没有修改 document.hidden 或只读诊断来伪造状态。未自动验证操作系统级真实切窗。
- 设置弹窗同样冻结天气；切节能不重置天气相位/预设。
- 薄雾转晴途中反选多云，保持混合状态继续，最后到达多云；没有直接跳成目标预设。
- **自动实跑 370.02 秒**，采样 740 个，三种状态全部出现，完整跨过一次周期边界。起点不是周期零点（接回原相位约 67.7 秒）；不冒充从零开始的计时。云偏移连续，未修改调试时间或内部状态。
- 三节点鸟瞰、谷地节点徒步均实际检查；1366×768、1920×1080 截图检查。首页控件最初与手记卡重叠，已改为顶栏折叠菜单，无水平溢出。
