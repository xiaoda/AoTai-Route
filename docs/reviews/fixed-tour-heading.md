# 漫游固定朝向修复验收

日期：2026-09-29。用户要求：空中漫游镜头方向不要自行晃动，保持向前。

## 原因及修复

原实现按路径切线逐帧改变基础 yaw。修复前，浏览器在没有视角输入时测得朝向从 2.61° 变化至 8.36°，然后又回转。新增整段固定朝向测试在旧代码上失败（初始 yaw 为 -0.0418047 而非 0）。

删除路径切线求角，自动基础朝向固定为 0（场景 -Z）。位置仍沿原路线、保持原速度与地形高度跟随，保留主动环顾和视角回正。俯仰不随路面坡度改变，滚转保持 0；不是把镜头转向改得更慢。

## 结果

- `npm test`：6 个文件、27 项通过。新增测试覆盖 3/6/12 米每秒 × 30/60/144 FPS，10/30 米高度、全路段、定位及重置，基础 yaw 始终为 0。
- `npm run build`：类型检查及生产构建通过，保留原有大包警告。
- 浏览器复用 PID 13548 / 127.0.0.1:49400，任务隔离页面 `aotai-fixed-heading-20260929-5196e`，pageId=3；未操作此前任务的 pageId=2，未启动新服务或可见终端。
- 快速档实际走到 181.73758 米终点；142 次相机旋转采样中 yaw/pitch/roll 的最大值减最小值均为 **0**，持续保持 `(0, -0.42, 0)`（这里顺序为 yaw、pitch、roll）。地图箭头始终 `rotate(0)`，终点自动暂停。
- 主动右转后 yaw=-0.49896；停止输入继续前进 1 秒后数值完全不变，未被路线重新带偏。
- 视角回正恢复 yaw=0、pitch=-0.42、roll=0。暂停期间距离增量 0；继续后位置前进、方向保持。
- 查看 1366×768 漫游和暂停实际截图，地图和界面正常。控制台无应用 error，仍有 Three.Clock 弃用 warning。
- 首次浏览器采样脚本遇到 React 按钮就绪时序，提前点击未启动漫游，脚本读地图时报空引用；确认实际按钮可用并用浏览器点击后重新完成上述验收，不将该次失败算作通过。

当前开发预览和 `dist/` 已包含修复；原阶段压缩包保持历史版本，未覆盖。没有重新宣称性能指标或生产运行验收，没有推送远程。

边界：本次固定的是镜头方向；飞行位置仍跟随弯曲路径，高度仍缓动跟随地形，并非恒定绝对高度的直线飞行。
