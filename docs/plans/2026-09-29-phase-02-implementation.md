# 阶段 2：真实高程与画面样段实施计划

> 执行方式：使用 executing-plans 分批实施、测试并汇报；本轮已获用户开始第二阶段授权。复用已有本机开发预览，不另开工作树或启动服务。

> **2026-09-30 状态更新：** 本文件记录 v0.2.0 的历史实施方案，不能作为视觉验收通过的依据。用户已明确反馈植被、重点景观、地域辨识度和路线长度不足；阶段 2 用户视觉验收未通过，需按[返工设计](2026-09-30-phase-02-visual-rework-design.md)重新制作和验收。

**目标：** 交付太白山高山区可体验的 v0.2 画面样段，保留固定朝向鸟瞰、小地图与徒步。
**架构：** 离线获取 Mapzen Terrarium 公开高程，转换为以米计的局部坐标和小型静态数据；渲染、碰撞、路线与地图共用高程。近景岩块/草簇原创程序建模，远景同源降采样，显示数据与艺术重建边界。
**技术栈：** 现有 Three.js / R3F / Rapier / TypeScript / Vitest；数据工具仅 Node.js 内置模块，不新增运行依赖。

## 设计决策与范围
- 备选 A 纯程序美术：便宜但不满足阶段真实性；B 真实高程 + 原创近景：本次采用；C 摄影扫描：需要额外授权、素材与更大资源预算，暂不采用。
- 候选中心 WGS84 107.76528 E、33.95512 N，太白山高山区；不将候选坐标视为实测峰顶。下载后检查高程和坡度再编排虚拟体验路径。
- 地形采用原始高程，垂直比例 1:1，不削峰填谷以迁就步道。路径是为虚拟体验编排的约数百米样段，不是现实 GPS 轨迹。
- 新增一个重点观景位置及数据说明。保持自然灰岩、枯金草甸和蓝灰远山的画面，不加入强景深、动态模糊和自动转头。
- 声音、动态天气、长时存档和全线扩展不属于本阶段。

## 第一批：数据与可复现地形
1. 新建 scripts/dem.mjs 与对应测试：Terrarium PNG 解码、像素中心约定、空值/长度检查、米制坐标转换与插值；先运行失败测试，再实现。
2. 新建 scripts/import-terrain.mjs：仅请求已验证公开 HTTPS 数据地址，限时/限尺寸，校验 SHA256，保留 URL、下载日期、响应来源、原始数据哈希及输出摘要。原始大文件缓存 .preview/，衍生小数据入 src/data/。
3. 新建 src/world/elevation.ts 与测试，读取并验证版本化网格，禁止静默替代为程序假山。检查覆盖、空值、高程范围、采样误差；记录源数据精度与高程基准。

## 第二批：实时画面与交互
4. 修改 terrain.ts、route.ts、simulation/Experience 接线与测试：共享真实网格、虚拟路线、起终点、重点视点；碰撞与地表一致、有效坡度检查，保留固定镜头。
5. 修改 Landscape.tsx：同源远山/近地形，无重叠闪烁/缺口；实例岩块与草簇、细节材质、自然静态光和空气透视；节能档减少非碰撞装饰，不降低地形碰撞精度。
6. 修改 App.tsx、MiniMap.tsx 与 styles.css：第二阶段说明、实际样段距离、高程/来源说明、同源等高线与观景标记；保持原有速度/暂停/回正操作。

## 第三批：验收与产物
7. 运行全部 Vitest（线程池）、tsc、Vite 构建；全程直接隐藏 node.exe、shell:false，记录 PID/cwd/退出码和输出。
8. Chrome DevTools 本任务独立 pageId：初始/鸟瞰/徒步/暂停/终点/画质、地图同步、方向恒定；实际截图检查近景和远山，记录 1080p 帧耗时/绘制量。仅开发预览验收，不将其冒充生产运行。
9. 更新 README、来源台账、路线图与 docs/reviews/phase-02.md；保留版本化构建快照和已知限制，不自动推送或合并 main。

## 验收门槛
- 获取失败、空值或边界/许可证不明则明确报告，不能将程序场景标为已完成真实地形。
- 地形与来源数据一致；无夸大测量精度；近景位置/植被/光照明确为艺术重建。
- 单测覆盖地理轴向、原始数据与衍生网格对应、接缝、路线坡度、碰撞、鸟瞰固定方向和小地图。
- 普通电脑目标 30 FPS，报告实测环境而非泛化保证；保留用户体验反馈环节。

## 实施调整
- Skadi 单文件约 16 MB 下载超时；改用同服务 4 张 z12 Terrarium 瓦片，共 233346 字节。HTTP 元数据实际证实 SRTM 来源，而非凭覆盖范围猜测。
- 用户已确认太白山高山区：石海与远山。
- 近景采用 1024 米 / 128 段；远景 8192 米 / 128 段，以边界细分三角扇真实缝合，无裙边遮洞或随意高度修改。

- 虚拟路径调整到较开阔的山脊：局部 Z=60 至 -320，约 382.62 米；石海观景标记位于 Z=-64。没有改动高程迁就路径。
- 浏览器截图检查暴露坡面岩块悬浮：增加局部法线四元数与埋入量，渲染/物理共同使用，并补单测与实际画面回归。
- 新增驻足看景开关：保持当前位置但不显示暂停菜单；与 Esc/失焦暂停分别处理。
