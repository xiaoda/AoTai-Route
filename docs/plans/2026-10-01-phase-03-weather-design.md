# 阶段 3：动态天气设计（无声音）

日期：2026-10-01。基线：a84199f。用户已确认晴朗、多云、薄雾，无雨雪；明确不做声音。

## 范围与体验

- 保留 2.23 公里及三个已验收节点，天气是艺术化环境编排，不接实时天气 API，不是气象模拟或实地安全信息。
- 默认六分钟循环：晴朗停留 → 多云渐入 → 多云停留 → 薄雾渐入 → 薄雾停留 → 放晴。连续插值，所有光照、雾和云共用状态。
- 右上提供自动 / 晴朗 / 多云 / 薄雾。固定的是天气类型，云仍缓缓移动。手动切换约 12 秒渐变；中途反选从当前画面继续，不跳变。
- 暂停、设置弹窗、失焦和隐藏页面冻结天气及云漂移；驻足仍可看天气变化。恢复首帧不累计后台时间。
- 仅持久化选择，旧设置自动补默认值，不保存循环进度。不做音频、降水、雷电、日夜、存档、章节或外部依赖。

## 架构

设置 / 控件 → WeatherController（纯数值、可测试）→ 统一 uniforms → 天空 + 雾 + 太阳 / 环境光 + 全部地表云影。

WeatherController 维护循环时刻、云漂移时刻、连续权重和手动过渡；每帧只改 ref / uniform，界面低频更新。只读诊断公开真实当前权重、参数和时间，不提供设置时间或改位置的测试捷径。

## ADR：轻量云图，而非体积云

选择固定种子、可平铺的本地程序云图，在天空球上投影成高空云层；沿同一光向在地形、石块、碎石和植被的直接光上投影同一云影。没有额外全屏后处理或体积光线步进，也无需每帧更新阴影贴图。雾使用现有指数距离雾，薄雾保留近处步行辨识度。

代价：云是平面层近似，雾不是山谷体积雾，不宣称照片级或物理气象准确。节能档减少天空细节采样，保留天气阶段和碰撞。

## 风险与验证

- 状态：循环边界、暂停/恢复、大 delta、手动中途切换、固定回自动、非法设置都用单元测试。
- 渲染：组合材质 hook 不覆盖原材质逻辑；验证标准与节能、三节点、实际截图和控制台。固定晴朗保留原始光照及雾基线。
- 性能：相同机位、分辨率、浏览器、单页驻足基线前后比较；记录平均/P95，不许承诺稳定帧率。
- 失败：沿用现有场景错误边界与 WebGL 中断提示；无在线资源依赖；设置写入失败仍能当次使用。
- 交付：测试/类型/构建、浏览器交互、三天气截图、来源说明、无声范围文档和源码/构建快照。最终视觉体验由用户验收。
