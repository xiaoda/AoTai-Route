# 漫游固定朝向修复计划

**目标：** 用户要求空中漫游镜头方向不要自行变化，始终向前。

**原因：** `AirTour.pose()` 按当前位置前后路径点计算切线 yaw，`Experience` 每帧把该角度叠加到用户视角。路径左右弯曲时，即使没有任何输入，镜头也不断转向。

**方案取舍：** 减慢/平滑转向只能减轻，不能满足方向不动；改成直线飞行会偏离既有路线。因此保留路径与高度跟随，只把自动基础 yaw 固定为 0（本测试场景前进总方向为 -Z）。俯仰沿用固定鸟瞰角，滚转为 0；主动环顾仍保留，松开后不再自动改向，回正恢复固定正前方。不引入新设置、新依赖或路径改动。

## 实施与验收

1. 修改 `src/world/tour.test.ts`：新增整段路线在 10/30 米高度、不同速度与帧率下 yaw 恒为 0；定位、重置也不改变基础朝向。先运行并确认旧实现失败。
2. 最小修改 `src/world/tour.ts`：删除前后路径点的切线求角，返回固定基础朝向；保留位置、弧长、速度、终点和高度逻辑。
3. `src/scene/Experience.tsx` 只补充固定朝向注释及只读相机旋转诊断，用于验证最终镜头，而非只验证数学模块。
4. `npm test` 与 `npm run build` 全量回归。浏览器复用 127.0.0.1:49400，使用本任务独有隔离页面，采样实际相机 yaw/pitch/roll；验证无输入移动时恒定、手动转头后保持、回正、暂停/继续和小地图朝向一致。
5. 更新当前设计与 README，另存修复验收记录；保留此前阶段验收的历史数据。本次不推送、不部署、不另启终端或预览服务。
