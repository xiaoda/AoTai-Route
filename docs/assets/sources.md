| 石河—草甸分区 | world/habitat.ts | 为首视点编排的地貌模式，不是遥感分类、真实石河位置或植被实测图 |
| 岩石/草甸程序材质 | scene/surface.ts | 原创 256×256 细节纹理、1024×1024 近景 / 512×512 远景分区图，运行时生成；非摄影扫描，未采样参考照片 |

| 字体 | 本机既有系统字体 | 未复制或分发字体文件，无线上字体请求 |
| 音频 | 无 | 第三阶段再落实 |
