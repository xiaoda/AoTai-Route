# 鳌太行旅 · 山野手记

普通电脑浏览器优先的山地体验。当前为 **阶段 2 / v0.2.0 太白山高山区地形与画面样段**，已完成开发自测，等待用户对画面和舒适度反馈。

> **山体与远山使用公开真实高程，岩石、草簇、材质、光照与体验路径为艺术化重建。** 数据不是最新实测、不是逐石扫描或现实导航轨迹；插值不提升原始测量精度。详见 [来源与精度说明](docs/assets/sources.md)。

## 第二阶段新增

- 太白山高山区：1024 × 1024 米近景、8192 × 8192 米同源远山；米制尺度、无高度夸大。
- 4 张公开 Mapzen / SRTM 高程瓦片，本地衍生网格约 202 KB；运行时无需请求地图服务。
- 三组原创岩块、坡面贴合、碎石与稀疏草簇、自然光及静态空气透视。
- 近远网格边缘细分缝合，地面与 Rapier 碰撞同源；节能档保留完整碰撞。
- 实时 DEM 等高线小地图、地面高程和虚拟石海观景点。
- “驻足看景 / 继续前进”：停止自动前进但不弹出遮景菜单，仍可主动环顾。

## 保留的体验能力

- 第一人称行走、上下坡、低台阶与岩块碰撞。
- 同源显示／碰撞地形，固定时间步与画面插值。
- 暂停、失焦自动暂停、回到起点。
- 鼠标锁定转头；不可用时支持按住画面拖动或方向键转头。
- 灵敏度、视野、可选轻微镜头晃动、节能／均衡画质。
- 本机设置保存、实时性能面板与图形异常提示。
- 半空自动漫游：默认离地约 30 米，亦可选择 10 米低空；3 / 6 / 12 米每秒，默认 6。
- 实时小地图：与场景同源的路径、当前位置、视线朝向、起终点、漫游进度。
- 终点自动暂停、重新漫游、暂停页切换徒步／漫游，保留徒步位置。

暂无音频、动态天气、章节和旅程存档。自动游览按用户反馈提前交付，但不代表阶段 3 的声音与天气已完成。

## 本地运行

开发环境使用 Node.js 24.14.0、npm 11.9.0。建议使用同代 Node.js LTS；依赖版本已锁定。

```powershell
npm ci
npm run dev
```

打开终端打印的 `http://127.0.0.1:端口/`，不要直接双击 HTML。默认端口占用时命令会明确失败，可用 `npm run dev -- --port <空闲端口>` 指定其他端口。服务仅监听本机，不对外开放。

验证与构建：

```powershell
npm test
npm run build
npm run preview
```

`dist/` 为生产构建。当前已通过类型检查与构建，但本次新生产预览进程启动被工具策略拒绝；已运行的开发预览用于浏览器验收，不能将其报告为生产运行验收。

## 操作

| 操作 | 按键 |
| --- | --- |
| 鸟瞰自动游览 | 首页选择“半空漫游”，无需按 W |
| 漫游速度／高度 | 左下控制台：3 / 6 / 12 米每秒，10 / 30 米高度 |
| 漫游暂停／恢复 | 空格（焦点不在表单和按钮上时）；也可点暂停或继续 |
| 驻足看景 / 继续前进 | 左下控制台，保持位置但不遮挡山景 |
| 漫游视角回正 | 左下“视角回正” |
| 行走 | W / A / S / D |
| 环顾 | 鼠标；锁定不可用时按住画面拖动或使用方向键 |
| 慢行 | 按住 Shift |
| 暂停／释放鼠标 | Esc |
| 显示性能面板 | P 或右上角按钮 |
| 调整设置／回到起点 | 暂停界面 |
| 切换徒步／漫游 | 暂停页“切换自由徒步／半空漫游” |

设置保存在浏览器 `aotai.settings.v1` 中；不同端口属于不同来源，设置不一定共享。设置不包含旅程进度。离开标签页或窗口失焦会停止移动。

漫游默认固定看向正前方，**不会随路径弯曲自动转头**；俯仰固定，无滚转和行走晃动。位置仍沿路径前进、高度仍跟随地形。漫游不锁定鼠标，可主动拖动画面或用方向键环顾；松开后保持所选方向，“视角回正”恢复正前方鸟瞰。徒步切入漫游会定位到最近路径点；切回徒步会返回此前保留的徒步位置，不是在当前空中位置降落。“重新漫游”仅重置漫游，“回到起点”会重置两种模式。速度和高度仅在本次页面会话保留，刷新恢复默认。

当前虚拟路径水平长度约 **383 米**，标准速度约 **64 秒**，快速约 **32 秒**；徒步约数分钟（坡度会影响实际耗时）。这是太白山高山区短样段，不是完整鳌太线或现实路线；小地图不是实地导航工具。

## 体验建议

1. 点击“半空漫游”，默认鸟瞰 30 米、6 米每秒，观察右下小地图。
2. 在地图的“石海观景点”附近点击“驻足看景”，观察近景与远山；点击“继续前进”恢复。
3. 试试舒缓／快速、拖动转头和视角回正；空格或 Esc 进入暂停菜单。
4. 按 Esc 切回徒步或调整灵敏度。容易眩晕时选择舒缓，并保持“行走晃动”关闭。
5. 若卡顿，选择节能画质；该档不降低地形碰撞精度。
6. 反馈“山形尺度、岩石/草甸基调、流畅度是否满意”。本阶段待体验反馈，不自动进入阶段 3。

## 高程数据再生成

通常不需要重新下载，仓库已经包含裁切网格。需要审计/重建时运行 `node scripts/import-terrain.mjs`（Node.js 24）。只访问指定 AWS 公开瓦片，原始文件缓存 `.preview/terrain-source/`；重新生成会检查已记录的 SHA256，上游变化会报错而非悄悄替换。

该样段使用 z12 瓦片约 31.7 米地面采样；上游标注 SRTM 约 90 米名义质量。8 米近景网格是插值结果，不能当作 8 米精度。摄影参考仅用于地貌对照，未复制进分发资产。

Windows 自动化执行遵循 [AGENTS.md](AGENTS.md)：直接隐藏 Node/Git 进程，不走 npm.cmd / 可见 shell；以上 npm 命令仅供用户手动运行。
