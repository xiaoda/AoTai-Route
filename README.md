# 鳌太行旅 · 山野手记

普通电脑浏览器优先的山地体验。当前为 **阶段 1.1 / v0.1.1 鸟瞰漫游与小地图原型**，根据首轮“步行太慢”的反馈迭代，等待用户再次体验。

> 当前地形、岩石和远山均为原创程序测试场景，**不是鳌太实测地形或现实导航路线**。真实地形与更精细的视觉资产将在后续阶段核实与制作。

## 本阶段已实现

- 第一人称行走、上下坡、低台阶与岩块碰撞。
- 同源显示／碰撞地形，固定时间步与画面插值。
- 暂停、失焦自动暂停、回到起点。
- 鼠标锁定转头；不可用时支持按住画面拖动或方向键转头。
- 灵敏度、视野、可选轻微镜头晃动、节能／均衡画质。
- 本机设置保存、实时性能面板与图形异常提示。
- 半空自动漫游：默认离地约 30 米，亦可选择 10 米低空；3 / 6 / 12 米每秒，默认 6。
- 实时小地图：与场景同源的路径、当前位置、视线朝向、起终点、漫游进度。
- 终点自动暂停、重新漫游、暂停页切换徒步／漫游，保留徒步位置。

暂无音频、动态天气、真实地形、章节和旅程存档。自动游览按用户反馈提前交付，但不代表阶段 3 的声音与天气已完成。

## 本地运行

开发环境使用 Node.js 24.14.0、npm 11.9.0。建议使用同代 Node.js LTS；依赖版本已锁定。

```powershell
npm ci
npm run dev
```

打开终端打印的 `http://127.0.0.1:端口/`，不要直接双击 HTML。默认端口占用时命令会明确失败，可用 `npm run dev -- --port <空闲端口>` 指定其他端口。服务仅监听本机，不对外开放。

验证与构建：

```powershell
npm test
npm run build
npm run preview
```

`dist/` 为生产构建。当前已通过类型检查与构建，但本次新生产预览进程启动被工具策略拒绝；已运行的开发预览用于浏览器验收，不能将其报告为生产运行验收。

## 操作

| 操作 | 按键 |
| --- | --- |
| 鸟瞰自动游览 | 首页选择“半空漫游”，无需按 W |
| 漫游速度／高度 | 左下控制台：3 / 6 / 12 米每秒，10 / 30 米高度 |
| 漫游暂停／恢复 | 空格（焦点不在表单和按钮上时）；也可点暂停或继续 |
| 漫游视角回正 | 左下“视角回正” |
| 行走 | W / A / S / D |
| 环顾 | 鼠标；锁定不可用时按住画面拖动或使用方向键 |
| 慢行 | 按住 Shift |
| 暂停／释放鼠标 | Esc |
| 显示性能面板 | P 或右上角按钮 |
| 调整设置／回到起点 | 暂停界面 |
| 切换徒步／漫游 | 暂停页“切换自由徒步／半空漫游” |

设置保存在浏览器 `aotai.settings.v1` 中；不同端口属于不同来源，设置不一定共享。设置不包含旅程进度。离开标签页或窗口失焦会停止移动。

漫游不锁定鼠标，按住画面拖动或用方向键环顾。徒步切入漫游会定位到最近路径点；切回徒步会返回此前保留的徒步位置，不是在当前空中位置降落。“重新漫游”仅重置漫游，“回到起点”会重置两种模式。速度和高度仅在本次页面会话保留，刷新恢复默认。

当前测试路径水平长度约 **182 米**，标准速度约 **30 秒**走完，快速约 **15 秒**。这是功能样段，不是完整鳌太线或长时旅程；小地图不是现实导航地图。

## 体验建议

1. 点击“半空漫游”，默认鸟瞰 30 米、6 米每秒，观察右下小地图。
2. 试试舒缓／快速、拖动转头和视角回正；空格暂停后检查位置是否停止。
3. 按 Esc 切回徒步或调整灵敏度。容易眩晕时选择舒缓，并保持“行走晃动”关闭。
4. 若卡顿，选择节能画质；该档不降低地形碰撞精度。
5. 反馈“高度是否合适、速度是否舒服、小地图是否清楚”，再进入阶段 2。
