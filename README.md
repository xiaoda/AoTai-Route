# 鳌太行旅 · 山野手记

普通电脑浏览器优先的山地体验。当前为 **阶段 2 第二批：2.23 公里连续样段、三处观景节点**。

首批石河视点已于 2026-09-30 获用户验收通过；第二批已扩线，**整段视觉效果仍待用户验收**，不自动进入第三阶段。用户已确认第三点采用“谷地与群峰远眺”，不虚构资料不足的大爷海湖面。

> 山形和远山使用公开 DEM；岩石、草甸、材质、光照、相机机位和路径为艺术化重建。这不是完整鳌太线、GPS 轨迹或实地导航。8 米插值网格不等于 8 米测量精度。详见[来源台账](docs/assets/sources.md)。

## 本批内容

- 原约 383 米路径完整保留为中段，向两端延伸至 **水平 2229 米 / 贴地约 2306 米**。DEM 采样累计上升约 272 米、下降约 213 米；没有夸大山体或压缩水平尺度。
- 三个虚拟节点：**风脊草坡 → 石河与草甸 → 谷地与群峰**。可主动选择鸟瞰或徒步并驻足；路过节点只更新文字，不自动转头或跳转。
- 近景扩为 2048 × 2048 米（256 段、8 米网格），远景仍为 8192 × 8192 米；原 1024 米核心区所有高程顶点保持一致。
- 7235 个同源显示/碰撞岩块；全样段 133173 个草簇/低矮叶片丛候选实例，按视距渐隐及分块裁剪，不是同时全量绘制。数量和分布是艺术编排，非植被调查。
- 岩块按 256 米块视锥裁剪并共享几何/材质；阴影随相机分区更新；节能档减少装饰和像素比，不简化碰撞。
- 同一份路径驱动地表净空、物理验证、节点、漫游和地图；小地图显示三处节点、起终点、实际比例尺和当前位置。
- 全部高程数据本地打包，沿用原四张固定哈希瓦片，无新增运行依赖或在线资源请求。

暂无音频、动态天气、完整章节系统和旅程存档。节点标题的分段提示不等于第三阶段的章节系统。

## 本地运行

开发环境 Node.js 24.14.0、npm 11.9.0，依赖版本已锁定。用户手动运行：

```powershell
npm ci
npm run dev
```

打开终端实际输出的 http://127.0.0.1:端口/，不要双击 HTML。指定端口已占用时会失败，可通过 --port 指定空闲端口。仅监听本机，不对外公开。

测试与构建：npm test、npm run build；生产构建在 dist/，可用 npm run preview 提供 HTTP 预览。

本批浏览器检查复用开发服务，生产构建通过不等于生产运行验收。Windows 自动化遵循 [AGENTS.md](AGENTS.md)，直接隐藏启动 node.exe，不经 npm.cmd 或可见 shell；以上 npm 命令仅供用户手动运行。

## 如何验收

1. 首页点“漫游完整样段”，默认 6 米/秒约 **6 分 12 秒**；快速 12 米/秒约 **3 分 6 秒**，舒缓约 12 分 23 秒。不含主动停留、暂停和卡顿。
2. 首页右侧或体验左上的三个节点可直接选景，进入后驻足；“鸟瞰此节点 / 徒步此节点”切换观察尺度。
3. 对照风脊草坡的绿色连续坡面、已验收石河、裸岩山肩的谷地群峰，检查辨识度、真实尺度和景观变化。
4. 鸟瞰下点“继续前进”，检查沿路变化、地图进度和终点；卡顿时切换节能。
5. 最终由用户判断整段是否达到“看起来有鳌太辨识度与真实尺度”，技术测试不代替视觉验收。

## 操作

| 操作 | 方式 |
| --- | --- |
| 全路线自动游览 | 首页“漫游完整样段”，不需按 W |
| 快速观景 | 首页节点 / 左上“风脊、石河、远眺” |
| 漫游速度 / 高度 | 左下 3 / 6 / 12 米每秒，10 / 30 米 |
| 驻足 / 前进 | 左下“驻足看景 / 继续前进” |
| 徒步 | W / A / S / D，Shift 慢行 |
| 环顾 | 鼠标；未锁定时拖动画面或方向键 |
| 暂停 | Esc；漫游也支持空格（焦点非表单/按钮时） |
| 重置 / 模式切换 | 暂停菜单 |
| 性能 | P 或右上按钮 |

完整漫游默认朝北，观景入口采用各节点编排视向；此后不会随路径弯曲自动转头。主动环顾后保持所选方向，“视角回正”恢复朝北鸟瞰。徒步切半空定位到最近路径点，切回徒步返回先前徒步位置，并非原地降落。“重新漫游”只重置漫游，“回到起点”重置两种模式。失焦自动暂停。

本机设置存于 aotai.settings.v1，不保存旅程；不同端口不共享。速度、高度仅在本次页面会话保留。

## 项目与资料

- src/world/journey.ts：单一路线与观景节点配置。
- src/world/route.ts：弧长、投影、净空空间索引、里程统计。
- src/world/：DEM、地表分区、装饰、物理和测试。
- src/scene/：R3F 场景、材质、分块绘制、相机与输入。
- src/components/MiniMap.tsx：同源等高线和路径地图。
- scripts/import-terrain.mjs：校验固定哈希缓存并重建 DEM；原始缓存只在 .preview/terrain-source/。

通常无需重新下载，仓库包含衍生网格。需要审计时运行 node scripts/import-terrain.mjs；原四张 PNG 可重建相同高程。来源变更会停止而非悄悄替换。摄影参考只本机对照，未放入代码或分发素材。
