# 鳌太行旅 · 地理导览

当前版本 **v0.4.0：从鳌山，到太白**。2026-10-02 用户确认调整主体验：暂不沿原阶段计划推进，以地理认识和旅程连续性为先。

## 现在打开会看到什么

- 默认是整段区域地形图，而非直接进入虚拟草坡。用真实 DEM 晕渲展示鳌山与太白山的相对位置。
- 五处精选地理锚点：**鳌山 → 麦秸岭 → 太白梁 → 大爷海 → 拔仙台**。坐标、资料海拔和来源集中在 src/journey/landmarks.ts。
- 开始导览后默认按顺序转场；每站停留 9 秒、转场 14 秒，约 101 秒完成；可暂停、选择地点、逐站跳转、倍速、看全貌及回顾。播放时间不是现实用时。
- “立体地形”使用这片区域的同源高程，支持看向前方/回望来路。它是 DEM 地形示意，未复刻步道、建筑、植被或湖岸；大爷海只是位置标记。
- “地貌漫游”保留原 2.23 公里虚拟样段、天气及稳定镜头。进入前暂停主导览，返回保留主导览地点；不会把原虚拟节点更名成真实地标。
- 全程无声。切出窗口暂停，返回后手动继续；减弱动态偏好采用逐站浏览。位置不跨刷新存档。

> **真实性边界：不是完整鳌太全线，也不是 GPS 轨迹。** 点间直线仅表达导览顺序和大致方向，中间省略了多个路段，不沿每一道山脊或道路。大爷海—拔仙台是本次展览顺序，不代表唯一现实线路。社区点位不是测量控制点。仅用于数字地理展览，不提供现实通行指引。

## 新导览的实现与数据

- src/JourneyApp.tsx：新默认入口、播放控制、资料弹窗、模式返回。
- src/journey/model.ts：纯函数导览状态、地图投影和聚焦范围。
- src/journey/JourneyMap.tsx：地形图、地标、转场位置与地图镜头。
- src/journey/TerrainView.tsx：独立按需加载的区域立体地形。
- public/journey/：本地地形、晕渲图、来源说明与独立 OSM 湖泊点位数据。
- scripts/import-journey-terrain.mjs：复用 Terrarium 解析器；24 张固定哈希瓦片，原始缓存只在 .preview/terrain-source/。

首页不加载 Three.js、物理引擎或旧样段高程；进入对应模式才加载。运行时不需要在线地图、账号或密钥。

技术验收与已知边界见 [地理导览检查记录](docs/reviews/2026-10-02-journey.md)。本次实施检查点见 [记录](docs/plans/2026-10-02-geographic-journey.md)。最终穿越感仍待用户体验验收。

## 沿用的地貌样段（以下为原阶段 2 / 3 说明）

原样段山形和远山使用公开 DEM；岩石、草甸、材质、光照、相机机位和路径为艺术化重建，不是现实 GPS 路线。近景 8 米插值网格不等于 8 米测量精度。详见[来源台账](docs/assets/sources.md)。

## 阶段 3：动态天气（无声）

- 默认六分钟循环：晴朗 → 多云 → 薄雾 → 放晴；光照、天空、远山雾气同步连续变化。
- 右上天气摘要展开后可选自动或固定晴朗/多云/薄雾。手动切换约 12 秒渐变；中途反选从当前画面继续。固定类型不停止云移动。
- 同一张原创程序云图驱动天空云层及山坡、岩石、草木上的云影；没有体积云、雨雪、雷电、声音或实时气象请求。
- 暂停、打开体验设置、切出窗口均冻结天气与云漂移；恢复不追赶后台时间。驻足仍可看天气变化。
- 均衡/节能共用天气与碰撞；节能少一层天空细节采样，沿用较低像素比和关闭实体阴影。
- 天气选择保存在原设置中，旧设置自动兼容；不保存循环进度。重载自动从晴朗开始，固定天气从该预设开始。
- 仅为离线艺术化气氛：云是平面层近似，雾是距离雾，不是气象模拟、山谷体积雾或导航依据。

详见[阶段 3 技术检查记录](docs/reviews/phase-03-weather.md)。

## 沿用的阶段 2 内容

- 原约 383 米路径完整保留为中段，向两端延伸至 **水平 2229 米 / 贴地约 2306 米**。DEM 采样累计上升约 272 米、下降约 213 米；没有夸大山体或压缩水平尺度。
- 三个虚拟节点：**风脊草坡 → 石河与草甸 → 谷地与群峰**。可主动选择鸟瞰或徒步并驻足；路过节点只更新文字，不自动转头或跳转。
- 近景扩为 2048 × 2048 米（256 段、8 米网格），远景仍为 8192 × 8192 米；原 1024 米核心区所有高程顶点保持一致。
- 7235 个同源显示/碰撞岩块；全样段 133173 个草簇/低矮叶片丛候选实例，按视距渐隐及分块裁剪，不是同时全量绘制。数量和分布是艺术编排，非植被调查。
- 岩块按 256 米块视锥裁剪并共享几何/材质；阴影随相机分区更新；节能档减少装饰和像素比，不简化碰撞。
- 同一份路径驱动地表净空、物理验证、节点、漫游和地图；小地图显示三处节点、起终点、实际比例尺和当前位置。
- 全部高程数据本地打包，沿用原四张固定哈希瓦片，无新增运行依赖或在线资源请求。

按用户要求不做音频；暂无雨雪、完整章节系统和旅程存档。节点标题的分段提示不等于第三阶段的章节系统。

## 本地运行

开发环境 Node.js 24.14.0、npm 11.9.0，依赖版本已锁定。用户手动运行：

```powershell
npm ci
npm run dev
```

打开终端实际输出的 http://127.0.0.1:端口/，不要双击 HTML。指定端口已占用时会失败，可通过 --port 指定空闲端口。仅监听本机，不对外公开。

测试与构建：npm test、npm run build；生产构建在 dist/，可用 npm run preview 提供 HTTP 预览。

天气功能与完整循环检查复用开发服务；另以本机生产 HTTP 服务验证了首页、薄雾徒步和设置重载，不将构建通过单独当作运行验收。Windows 自动化遵循 [AGENTS.md](AGENTS.md)，直接隐藏启动 node.exe，不经 npm.cmd 或可见 shell；以上 npm 命令仅供用户手动运行。

## 如何验收天气

1. 从右侧选择“石河与草甸”或“谷地与群峰”，在固定机位驻足。
2. 展开右上天气手记，依次选择晴朗、多云、薄雾；每次等待约 12 秒，观察远山层次、天空与山坡明暗。
3. 自动模式约六分钟前台体验完成一轮；切换回自动会平滑接回原来的循环位置。
4. 暂停或切出窗口再回来，确认云雾没有突然跳变；继续体验后再演进。
5. 性能不足可在体验设置切节能。此阶段没有任何声音。

## 如何验收既有样段

1. 首页点“漫游完整样段”，默认 6 米/秒约 **6 分 12 秒**；快速 12 米/秒约 **3 分 6 秒**，舒缓约 12 分 23 秒。不含主动停留、暂停和卡顿。
2. 首页右侧或体验左上的三个节点可直接选景，进入后驻足；“鸟瞰此节点 / 徒步此节点”切换观察尺度。
3. 对照风脊草坡的绿色连续坡面、已验收石河、裸岩山肩的谷地群峰，检查辨识度、真实尺度和景观变化。
4. 鸟瞰下点“继续前进”，检查沿路变化、地图进度和终点；卡顿时切换节能。
5. 最终由用户判断整段是否达到“看起来有鳌太辨识度与真实尺度”，技术测试不代替视觉验收。

## 操作

| 操作 | 方式 |
| --- | --- |
| 全路线自动游览 | 首页“漫游完整样段”，不需按 W |
| 快速观景 | 首页节点 / 左上“风脊、石河、远眺” |
| 漫游速度 / 高度 | 左下 3 / 6 / 12 米每秒，10 / 30 米 |
| 驻足 / 前进 | 左下“驻足看景 / 继续前进” |
| 徒步 | W / A / S / D，Shift 慢行 |
| 环顾 | 鼠标；未锁定时拖动画面或方向键 |
| 暂停 | Esc；漫游也支持空格（焦点非表单/按钮时） |
| 重置 / 模式切换 | 暂停菜单 |
| 性能 | P 或右上按钮 |

完整漫游默认朝北，观景入口采用各节点编排视向；此后不会随路径弯曲自动转头。主动环顾后保持所选方向，“视角回正”恢复朝北鸟瞰。徒步切半空定位到最近路径点，切回徒步返回先前徒步位置，并非原地降落。“重新漫游”只重置漫游，“回到起点”重置两种模式。失焦自动暂停。

本机设置（含天气选择）存于 aotai.settings.v1，不保存旅程与天气循环进度；不同端口不共享。速度、高度仅在本次页面会话保留。

## 项目与资料

- src/world/weather.ts：纯数值天气编排及暂停/渐变规则。
- src/scene/Weather.tsx、weatherMaterial.ts：统一天空、雾、光照与云影。
- src/world/journey.ts：单一路线与观景节点配置。
- src/world/route.ts：弧长、投影、净空空间索引、里程统计。
- src/world/：DEM、地表分区、装饰、物理和测试。
- src/scene/：R3F 场景、材质、分块绘制、相机与输入。
- src/components/MiniMap.tsx：同源等高线和路径地图。
- scripts/import-terrain.mjs：校验固定哈希缓存并重建 DEM；原始缓存只在 .preview/terrain-source/。

通常无需重新下载，仓库包含衍生网格。需要审计时运行 node scripts/import-terrain.mjs；原四张 PNG 可重建相同高程。来源变更会停止而非悄悄替换。摄影参考只本机对照，未放入代码或分发素材。
